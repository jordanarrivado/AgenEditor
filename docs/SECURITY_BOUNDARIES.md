# Security boundaries

Phase 5 audit and open findings: [`SECURITY_AUDIT.md`](SECURITY_AUDIT.md).

Derived from product spec §4.1, §6 and §11. Status column says what is enforced **today** versus planned.

| Boundary | Rule | Status |
|---|---|---|
| Agent → engine | Agents act only through typed MCP tools. No tool accepts shell commands, URLs, absolute paths, directories or FFmpeg filter strings. | Contracts reject unknown fields (`extra="forbid"`) and enumerate codecs/presets. MCP v2 stdio tools use typed inputs and project-scoped imports. |
| Paths | Every stored path is project-relative, POSIX, no `..`/absolute/drive/UNC/`:`/device names. Assets live under `originals/`. | Enforced by `ProjectRelativePath` and `Asset` validators (tested). The storage layer rechecks resolved paths and rejects symlinks and junctions at I/O time; cleanup never follows links (tested). |
| Source integrity | Originals are copied into `originals/`, hashed (SHA-256) and never written. Renders go to temp files, are verified, then published atomically. | Hashing + read-only probe tested. Imports copy to read-only originals; renders verify temp output before atomic publish. |
| Subprocesses | `subprocess.run`/`Popen` with argument lists, `shell=False` and a timeout; tool paths from PATH or `AGENEDITOR_FFMPEG`/`AGENEDITOR_FFPROBE`. | Enforced in probe, fixture generation, rendering and QA. Ruff `S` rules run in CI. |
| Concurrent edits | UI and MCP commit with `expected_revision`; conflicts return `REVISION_CONFLICT`. | SQLite `BEGIN IMMEDIATE` serializes commits; expected revision conflicts return `REVISION_CONFLICT`. |
| Local IPC | One per-user engine service; named pipe or 127.0.0.1 with an ephemeral token; never bound to LAN. | 127.0.0.1 HTTP with a 64-hex bearer token, constant-time check, 4 MiB body cap (tested). Discovery is stored outside projects with a current-user/SYSTEM-only DACL; bounded threaded requests reject hostile Host/Origin headers (tested). |
| Data leaving the machine | Raw media never uploaded. Transcripts/metadata sent to an external agent only with disclosure; UI shows what is shared. | MCP transcription runs with a local-only model and no download. The explicit `cache-model` CLI command downloads model files; external MCP hosts control their own model traffic. Sound packs: only a user click on a catalog entry downloads, from a fixed HTTPS URL on an allow-listed host (redirects rechecked), size-capped, SHA-256-pinned, then zip-extracted with path checks (no `..`, absolute or drive paths); no agent tool can trigger it (tested). Nothing is uploaded. The native handoff panel discloses transcript, filename and metadata sharing. **Polish with Opus** sends only the instructions text to Anthropic via Claude Code (no tools, no MCP, no saved session), disclosed next to the suggestion; nothing is saved unless the user accepts it. |
| First-run setup | Only the user's click installs anything; no silent downloads. | **Install Claude Code** runs Anthropic's official installer from the fixed URL `https://claude.ai/install.ps1` (PowerShell, current user, no admin, 15-minute timeout) and then requires a valid Authenticode signature whose signer name is exactly "Anthropic, PBC" on `claude.exe`. The same check gates every Claude run, Polish, usage read and status check (done once per file, repeated if its size or timestamp changes); a file that fails is never run and the setup screen says why. **Sign in** opens `claude auth login` in its own window. Status checks read `claude --version` and `claude auth status --json`; the UI receives only signed-in, plan and method, never the email or organisation (tested). |
| Built-in chat keys | API keys never cross back to the page. | `chat_set_key` writes to Windows Credential Manager (`AgenEditor/chat/<provider>`); `chat_status` returns only whether a key exists; provider error text is redacted of the key; chat sends text only after the person allows it per project, and a proposal changes nothing until a person applies it. |
| Opening generator sites | The page never supplies a URL to open. | `open_generator` accepts only the names `chatgpt`, `flow` and `aistudio` and opens the fixed addresses `https://chatgpt.com/`, `https://flow.google.com/` and `https://aistudio.google.com/generate-speech` in the default browser (no shell; tested). The prompt goes to the clipboard on the person's click; AgenEditor does not post it or read the result back. |
| MCP stdio hygiene | stdout carries protocol only; logs to stderr/files; tool args logged redacted in `agent_events`. | The stdio adapter keeps stdout for MCP; write actions store redacted IDs/status in `agent_events`. |
| Secrets | No API keys in repo or frontend. Future provider keys in OS credential storage. | No secrets present. |

Report security issues privately to the maintainer; do not open public issues for them.
