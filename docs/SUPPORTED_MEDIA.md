# Supported media

## Input

AgenEditor accepts whatever the bundled FFmpeg can decode, but only the cases below are **tested**
(synthetic fixtures generated by `ageneditor fixtures`). Treat anything else as unverified and check
the preview.

| Case | Status |
|---|---|
| H.264 + AAC in MP4, constant 30 fps, 16:9 and 9:16 | Tested |
| 29.97 fps (30000/1001) | Tested (rational timebase) |
| Variable frame rate phone footage | Tested (frame-accurate VFR mapping) |
| AAC music in M4A | Tested |
| Video-only B-roll | Tested |
| HEVC/H.265, ProRes, VP9, AV1 (dav1d) | The bundled FFmpeg includes these decoders; not tested with real files |
| Rotated phone footage (rotation metadata) | Recorded by the probe; **output orientation not yet verified** |
| HDR / 10-bit | Not tested; output is 8-bit SDR `yuv420p` without tone mapping |
| Multiple audio tracks | The first audio stream is used |
| PNG and JPEG stills | Implemented as V2 overlays with an explicit output duration; synthetic PNG media test has not run on this host |
| Other images, subtitle files as assets | Not supported in timelines yet |

Roles: `primary` (talking head, video with audio), `broll` (video or PNG/JPEG still), `music` (audio only), `logo`.

## Output

| | Value |
|---|---|
| Container | MP4 (`+faststart`) |
| Video | H.264 (libx264), `yuv420p`, profile resolution and frame rate (final reel: 1080×1920 at 30 fps; preview: ≤ 720×1280) |
| Audio | AAC, 48 kHz stereo, two-pass loudness normalisation to −16 LUFS integrated, −1 dBTP ceiling (configurable) |
| Captions | Burned in (fixed presets) and exported as `captions.srt` |
| Side files | `timeline.json`, `qa.json`, `render.log` per render |

Hardware encoders (NVENC, Quick Sync, AMF) are detected by `ageneditor system` but not used: renders
use libx264 so the same timeline produces the same frames on every machine.
